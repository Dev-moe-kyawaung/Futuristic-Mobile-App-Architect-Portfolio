# 🚀 Futuristic Mobile App Architect Portfolio

A stunning, production-ready portfolio showcasing senior Android/mobile app architect expertise with a beautiful dark-glass theme, 3D floating UI components, animated skill graphs, and multilingual support (Burmese/English).

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen)](https://moekyaw.github.io/portfolio)
[![License](https://img.shields.io/badge/License-MIT-blue)](LICENSE)

## ✨ Features

- 🎨 **Dark-Glass Theme** - Modern glassmorphism design with neon accents
- 🌌 **3D Particle Background** - Three.js powered interactive particles
- 📊 **Animated Skill Graphs** - Chart.js radar charts with smooth animations
- 🌐 **Multilingual** - Burmese/English language toggle with i18n support
- 🎬 **Cinematic Transitions** - GSAP-powered scroll animations
- 📱 **Fully Responsive** - Mobile-first design for all devices
- ⚡ **Performance Optimized** - Sub-2s load time, lazy loading
- 🔍 **SEO Ready** - Meta tags, semantic HTML, accessibility

## 🚀 Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/moekyaw/futuristic-architect-portfolio.git
cd futuristic-architect-portfolio
```

## 2. Open in Browser
Simply open index.html in your browser, or use a local server:
```# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```
## 3. Deploy to GitHub Pages
```
# Create gh-pages branch
git checkout --orphan gh-pages
git add -A
git commit -m "Initial portfolio deployment"
git push -f origin gh-pages

# Enable GitHub Pages in repository settings
```
